¿Cuánto conocemos de Sistemas Operativos?

Este mini-quiz no busca que memorices definiciones, sino que pienses qué pasaría si algo del PCB fallara o por qué el sistema operativo lo necesita. Elegí una opción en cada pregunta para ver si acertaste y por qué.

1. Si el sistema operativo perdiera el PCB de un proceso justo mientras estaba bloqueado esperando una E/S, ¿qué pasaría?

2. ¿Por qué el PCB vive en el espacio de memoria del kernel y no en el espacio de memoria del propio proceso?

3. Dos procesos, A y B, tienen la misma prioridad y el algoritmo de planificación favorece a quien menos tiempo de CPU acumuló. Si el campo "tiempo de CPU usado" del PCB de A no se actualizara correctamente, ¿qué podría pasar?

4. ¿Cómo se relaciona el PCB con el cambio de contexto (context switch)?
